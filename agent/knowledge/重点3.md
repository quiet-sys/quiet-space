概念

​			类的构成   （背）

​					1.隐藏代码

​					2.主方法

```java
	//主方法  作用 运行代码    写不写都行
	public static void main(String[] args) {
		
	}
```

​					3.成员变量


​					4.局部变量



​		3.作用特殊

static (背)

​		静态==类的    实例==对象的

​		成员变量

​			1.加static    静态成员/类成员

​			2.不加static  实例成员

​		普通方法

​			1.加static    静态方法/类方法

​			2.不加static  实例方法

​			所有加了static的内容都会优先加优先分配内存（只要类加载所有的静态公共资源全部会加载）

​			所有实例的公共资源只有new对象的时候才会分配内存 （分配内存叫初始化）

​			调用规则

​				1.对内  同一个类中

​					静态方法只能使用静态成员和其他静态方法

​				2.对外  不同类中

​					对象能调用静态和实例的公共资源 （但是不建议使用对象调用静态的公共资源）

​					实例公共资源统一使用对象调用

​					静态的公共资统一使用类名调用



资源交互方式(背)

不用类之间的公共资源要想交互

1.用对象调用

2.用类名调用 （静态的)

3.继承     A继承B    A 子类  B  父类  （团队语法）
