## 设计模式

### 单例模式

>单例 = 整个项目全局只有一个实例，所有地方共用它。
>
>```java
>public class TestOneExample {
>    private static final TestOneExample instance = new TestOneExample();
>    private TestOneExample() {
>    }
>    public static  TestOneExample getInstance(){
>        return instance;
>    }
>   }
>```
>
>

### 工厂模式

>去掉 if-else -> 后续可扩展
>
>后续只需要添加对应实体类 -> 即可
>
>```java
>public interface LoginStrategy {
>    User login(String account, String credential);
>}
>
>public class PasswordLogin implements LoginStrategy {
>
>    @Override
>    public User login(String account, String password) {
>    User user = new User("111","111");
>        System.out.println("密码登录");
>    return user;
>    }
>}
>
>public class SmsLogin implements LoginStrategy {
>
>    @Override
>    public User login(String account, String password) {
>        System.out.println("短信登录");;
>        return new User("111","111566");
>    }
>}
>
>```
>
>````java
>public class Factory {
>
>    public LoginStrategy createLoginStrategy(String type) {
>        //正常springboot 可以以此来直接获取
>        if(type.equals("sms")){
>            return new SmsLogin();
>        } else if (type.equals("password")) {
>            return new PasswordLogin();
>        }
>        return null;
>    }
>}
>````
>
>```java
>public class main {
>    public static void main(String[] args) {
>        Factory factory = new Factory();
>        LoginStrategy loginStrategy = factory.createLoginStrategy("password");
>        loginStrategy.login("111","111");
>    }
>}
>//工厂模式
>//根据不同的登录策略，创建不同的登录对象
>
>```
>
>

### 模板方法

>流程固定 -> 子类必须根据流程进行对应操作
>
>```python
>#ABC类，抽象父类，
>#@abstractmethod 抽象方法
>#evaluate方法，模板方法，固定流程
>class EvaluatorTemple(ABC):
>    def evaluate(self,source):
>        data = self.read_data(source)
>        analysis = self.analyze_data(data)
>        return analysis
>    @classmethod
>    @abstractmethod
>    def read_data(cls,source):
>        pass
>    @classmethod
>    @abstractmethod
>    def analyze_data(cls,data):
>        pass
>    
>    
>    class AudioEvaluatorTemple(EvaluatorTemple):
>    @classmethod
>    def read_data(self,source):
>        return source
>    @classmethod
>    def analyze_data(self,data):
>        return data
>    
>    
>if __name__ == "__main__":
>    evaluator = AudioEvaluatorTemple()
>    result = evaluator.evaluate("audio_file.mp3")
>    print(result)
>    
>```



### 观察者模式

>当被观察者发生改变时，观察者发生对应改变
>
>```python
>class Observe(ABC):
>    @classmethod
>    @abstractmethod
>    def update(self,data):
>        pass
>
>```
>
>```python
>class ToObserve(Observe):
>    def update(self,data):
>        print("ToObserve update",data)
>        
>class LoggerObserve(Observe):
>    def update(self,data):
>        print("LoggerObserve update",data)
>
>class EvalluationTask:
>    def __init__(self):
>        self._observes = []
>    
>    def attach(self,observe):
>        self._observes.append(observe)
>    
>    def notify(self,data):
>        for observe in self._observes:
>            observe.update(data)
>    
>    def run_evaluation(self):
>        self.notify("评估开始")
>        # 模型运行中...
>        self.notify("评估进行中...")
>        # 完成
>        self.notify("评估完成")
>
>if __name__ == "__main__":
>    task = EvalluationTask()
>    task.attach(ToObserve())
>    task.attach(LoggerObserve())
>    task.run_evaluation()
>
>
>```
