1.学习方法  死记硬背





概念

​			类的构成   （背）

​					1.隐藏代码

​					2.主方法

```java
	//主方法  作用 运行代码    写不写都行
	public static void main(String[] args) {
		
	}
```

​					3.成员变量

```java
	//成员变量  作用  公共资源 （*）   写不写都行
	int a = 100;
```

​					4.局部变量

```java
public static void main(String[] args) {
		
		int  b = 200;//局部变量  作用  辅助运算 辅助开发   写不写都行
		
}
```

​					5.普通方法

```java
	//普通方法 作用  公共资源 （*）   写不写都行
	public void add() {
		
	}
```

​					6.构造方法

```java
	//构造方法  作用 创建类的对象  写不写都默认存在
	public  Four() {
		
	}
```

​					7.静态代码块

```java
	//静态代码块   作用 最先执行   里面的代码只执行一次  写不写都行
	static {
		System.out.println("static");
	}
```

成员变量    直接声明或定义在类中的变量 == 全局变量  （背）

局部变量    声明或定义在方法中的变量包含方法的参数 （背）

构造方法    隐藏代码写不写都默认存在

​					方法名等于类名

​					构造方法不能拥有任何的返回值类型

​					用来配合new关键字创建类的对象



对象 （背）

每个类都能创建的一种特殊的变量

​		1.数据类型特殊	

​			用自己的类的名字作为数据类型    （自定义类型/类类型）

​		2.赋值方式特殊

​			用new关键字加上自己的构造方法赋值

​		3.作用特殊

​			用来调用 .   自己类中的公共资源


关键字（背）

void    方法返回值类型的一种表示当前的方法不返回任何数据

new    开辟一块内存空间给对象这种特殊的变量赋值   配合构造方法

static  修饰成员变量和普通方法 表示静态的或类的
