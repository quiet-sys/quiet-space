## HTML

#### 超文本标记语言：静态页面，

文本：就是一组字符序列

超文本：文本基础之上，添加图片 链接  视频等等等 



静态页面：HTML文件加载之后，内容和布局保持不变，不会根据用户操作从而发生更改

HTML不分区大小写，对错误也不敏感，简单，标签组成，没有变量 循环 分支 

HTML是不是编程语言？？？？

不是，具备条件：标签   HTML文件 不需要任何环境，浏览器 HTML 浏览器解析 运行 编译 



#### 标签分类

- 块级标签：宽度默认是100%，高度默认撑开，可以设置宽度和高度，标签与标签之间默认换行 
- 行级标签：宽度由内容自动撑起，高度也是一样的，可以设置宽度，高度设置不了 ，不会自动换行
- 行内块标签：可以设置高度·和宽度 但是 不换行
